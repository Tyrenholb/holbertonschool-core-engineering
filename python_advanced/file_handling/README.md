# Python File Handling

An introduction to reading and writing UTF-8 text files in Python.

## Functions

| Function | Description |
| --- | --- |
| `read_file(filename="")` | Reads a text file and prints its contents to stdout. |
| `write_file(filename="", text="")` | Writes a string to a file and returns the number of characters written. Creates the file if missing or overwrites existing contents. |

## Concepts Practised

- Opening files with `open()` and choosing the correct mode.
- Using `with` to close files automatically.
- Reading and writing text with UTF-8 encoding.
- Preserving line breaks without adding extra newlines.
- Returning values from functions.
- Writing docstrings and following PEP8 style.
