# Python Exception Handling

This project explores how Python handles runtime errors. The exercises use `try` and `except` to respond to invalid input or failed operations, and `raise` to create exceptions when needed.

## Learning objectives

- Recognise common exceptions such as `TypeError`, `IndexError`, `ZeroDivisionError`, and `KeyError`.
- Catch specific exceptions with `try` and `except`.
- Use `else` and `finally` where appropriate.
- Raise exceptions with custom messages.

## Requirements

- Ubuntu 20.04 LTS and Python 3.8.x
- Executable Python files beginning with `#!/usr/bin/env python3`
- A newline at the end of every file
- PEP8 style checked with pycodestyle 2.7.x
- No external libraries
- No broad `except:` blocks unless an exercise explicitly requires one
