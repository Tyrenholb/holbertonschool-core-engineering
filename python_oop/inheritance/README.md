# Python Inheritance and Polymorphism

## Introduction

This project explores inheritance and polymorphism by building a
geometry class hierarchy: BaseGeometry → Rectangle → Square.

## Learning Objectives

- Reuse parent methods through inheritance.
- Validate positive integers using shared logic.
- Initialize parent classes with super().
- Override methods to provide specialized behavior.
- Use private attributes and documentation strings.
- Implement readable object descriptions with __str__().

## Files

| File | Description |
|------|-------------|
| base_geometry.py | Defines the area interface and integer validator. |
| 1-rectangle.py | Adds a rectangle with validated private dimensions. |
| 2-rectangle.py | Implements rectangle area and string representation. |
| 1-square.py | Creates a square using the rectangle constructor. |
| 2-square.py | Adds a square-specific string representation. |
